# Product Overview

## What This Is

The **NMN Java Spring Boot AI-SDLC Framework** — a shared set of skills, rules, and standards that AI coding agents use to generate consistent, production-quality Java code across all NMN projects.

## Purpose

- Encode 18+ years of Java / enterprise best practice into structured skill files.
- Ensure every AI agent (regardless of tool) produces code that meets enterprise standards.
- Provide a single source of truth for coding conventions, architecture patterns, and operational practices.

## Target Users

- Java developers using AI coding assistants.
- Tech leads enforcing standards across teams.
- New developers onboarding to NMN Java projects.

## Key Features

- 18+ skill files covering code style through production operations.
- 4 framework-specific skills (Spring Boot, Spring WebFlux, Kafka, gRPC).
- QA agent definition for automated quality pipelines.
- Reference implementation in `examples/spring-boot-app/`.

## Business Objectives

- Reduce code review cycles by 50% (agent follows standards pre-review).
- Onboard new developers in < 1 week (agent teaches standards in context).
- Zero security incidents from hardcoded secrets or missing auth.
- Consistent architecture across all Java Spring Boot services.
